# Сайт «Фабрика заготовок»

Информационный сайт клуба Веры Малыгиной: рассказывает о системе заготовок, материалах и результатах участниц и ведёт на страницу вступления. Основной адрес: https://fabrikazagotovok.ru/.

## Файлы

- `index.html` — страница о клубе, преимущества, материалы, отзывы, FAQ, социальные ссылки и кнопки перехода к вступлению.
- `package.json` — команда сборки статической версии в `dist/`.
- `onreza.toml` — настройки публикации на ONREZA.

## Сборка и проверка

```sh
npm run build
```

Кнопки «Вступить в клуб» ведут на https://sales-platform-clubfabrika3.ru/. Оформление заказа проходит на сайте продаж, серверного checkout в этом проекте нет.

Перед публикацией проверьте мобильную и настольную ширину, ссылки и содержимое модальных окон. Слияние в `main` может запустить автоматическую публикацию.
